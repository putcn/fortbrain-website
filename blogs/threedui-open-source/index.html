ThreeDUI 开源：让业务界面真正进入 3D 空间ThreeDUI is open source: everyday interfaces in real 3D

从可输入的玻璃注册表单，到六视图业务工作空间：ThreeDUI 用 Vue 组件组织真实的 3D 界面，让图表、地图和仓储场景与日常操作共享空间。From an editable glass sign-up form to a six-view workspace, ThreeDUI uses Vue components to put everyday controls, charts, maps and warehouse content in one 3D scene.

我们已经把 ThreeDUI 开源。它要解决的问题并不是把仓库做成尽可能逼真的数字孪生，而是让开发者像写 Vue 界面一样，把常用的控件、表单和业务视图放进三维空间。新增的深度应该帮助人理解数据之间的关系、找到当前操作的位置，而不只是给平面卡片加一点透视。

现在可以直接打开两个演示：可输入的注册表单和六视图综合演示。前者适合检查组件本身：点击输入框可以打字，左键拖动平移、右键拖动旋转、滚轮缩放，可以从不同角度看玻璃控件的厚度与光照。后者把订单、Dashboard、网络地图、仓储孪生、库存和设置放在同一个空间工作区；从总览聚焦到某个视图，图表、地图和场景内容与操作界面共享相机和空间位置。两个演示都使用示例数据。

为什么需要第三个维度

传统网页擅长排版，却常常要把位置、层级和关联压成标签页与弹窗。ThreeDUI 的 Space 与 Block 让视图占据可理解的位置；聚焦一个视图时，镜头移动、邻近视图与场景内容仍然保留上下文。在仓储演示里，列表、路线、地图和库位模型是连续的工作流程，而不是六张互不相干的 2D 页面。

这也给玻璃材质一个合理的用途。控件有真实几何、光照和投影；玻璃的透明度与层叠关系可以表达可操作对象与背景数据之间的距离。注册表单是这个设计语言的基础样张，综合演示则检验它能否承载实际业务密度。

开发者如何使用

仓库提供 Vue 组件、布局与事件系统、文字输入和输入法支持、组件示例、完整演示、文档以及供 coding agent 参考的 skill。Surface 定义界面所在层，Space 管理空间工作区，Block 组织可聚焦的业务视图。现阶段是仓库内的 pnpm workspace 包，尚未发布 npm 正式版本；可以克隆仓库运行演示，并在 workspace 中试用组件。

我们会继续打磨性能、交互与视觉一致性。真正的检验标准不是某一张截图，而是开发者能否快速搭建、用户能否在有深度的界面里完成日常工作。

ThreeDUI is now open source. Our goal is not the most photorealistic warehouse twin. It is to let developers build everyday interfaces in three-dimensional space with a workflow that feels like writing Vue. Depth should make relationships between data and actions easier to understand, rather than merely tilt a collection of flat cards.

You can try two live examples: an editable sign-up form and a six-view application. In the form, click a field and type; left-drag to pan, right-drag to rotate, and scroll to zoom. This makes the controls' real thickness and lighting inspectable. The application brings orders, dashboard, network map, warehouse twin, inventory and settings into one workspace. Move from the overview into a view while charts, maps and scene content keep their spatial context. Both examples use sample data.

What the third dimension adds

Conventional web pages are excellent at layout, but often squeeze position, hierarchy and relationships into tabs and modal dialogs. ThreeDUI's Space and Block give views understandable positions. When a view receives focus, the camera moves while its neighbours and the shared scene preserve context. In the warehouse example, lists, routes, maps and locations form a connected workflow rather than six unrelated pages.

Glass also has a job to do here. Controls have real geometry, lighting and shadows. Transparency and layering can express the distance between an actionable surface and the data behind it. The sign-up form establishes the visual language; the full application tests whether it can carry realistic business density.

Building with it

The repository includes Vue components, layout and events, text entry and IME support, component examples, a complete demo, documentation, and an agent skill. Surface places an interface layer, Space manages a workspace, and Block groups a focusable view. These are currently pnpm workspace packages in the repository; no stable npm release has been published yet. Clone the repository to run the demos and try the components within the workspace.

We will keep refining performance, interaction and visual consistency. The real test is whether developers can build quickly and people can finish ordinary tasks in an interface with depth.
