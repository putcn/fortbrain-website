# Fortbrain 官网重做：滚动叙事 + 3D 城市地图 · 设计

- 日期：2026-09-15
- 状态：待用户评审
- 背景：现有官网是一页静态文案加极光背景。用户要推翻重做：视差滚动，背景是 Fortbrain
  销售大屏 / 仓储大屏那张徐州 3D 地图；开场提问，向下滚动逐点回答，每点镜头特写一个方块；
  滚到底镜头升空，出现极光式的「意识流」发光，落联系方式。中英双语，手机可用。

---

## 1. 目标与非目标

### 目标

1. 一个页面讲完一件事：**现代企业到底需要什么样的智能化**，答案是 Fortbrain 的六个特点。
2. 背景是**活的**：3D 城市地图慢转，门店方块高度随「销量」不断呼吸；每一点镜头飞到一个方块特写，
   方块各有材质与状态。
3. 中英双语，一键切换。
4. 桌面与手机浏览器都能看：手机上不掉帧、不劫持滚动、文字可读。
5. 仍是纯静态站，部署方式不变（GitHub Pages，域名 fortbrain.ai）。

### 非目标

- 不接真实数据。门店、销量、库存全部是演示数据，**不出现任何客户名称或地址**。
- 不做导航、多页、表单。整站只有一页和一个 mailto。
- 不追求大屏那种精细的交互（拖拽、缩放、点选）。镜头只由滚动驱动。

## 3. 总体架构

```
index.html            页面骨架：固定画布 + 滚动的文字段落 + 语言切换 + 联系
css/site.css          排版、段落进出场、响应式
js/i18n.js            中英文案表 + applyLang()；只管 DOM 文字，不碰场景
js/geo.js             地理算术（投影、散开、错位网格落位），从大屏 geo.js 移植，无 Three 依赖
js/scene.js           Three.js 场景：底图、方块（六种材质）、极光、镜头；对外只暴露 setProgress / tick / resize
js/story.js           把滚动进度映射成「第几段、段内进度」，喂给 scene；用 IntersectionObserver 控制文字进出场
js/layers.js          界面拆解段：三个 HTML 层的 CSS 3D 飞入 / 停留 / 飞出，由滚动进度驱动
js/fallback.js        WebGL 不可用时的 canvas 2D 极光（重新设计实现，见 §8.1，不沿用旧站代码）
data/xuzhou.json      简化后的徐州底图（< 300KB）
scripts/build-geo.py  从 ~/Fortbrain/packs/mxipos/app/geo/320300.json 生成 data/xuzhou.json（开发机跑一次，产物进仓库）
```

- Three.js 0.160 自托管在 `vendor/three/`（min build + 用到的两个 addon），importmap 指向本地；不引入构建工具。（原用 jsdelivr CDN，2026-09-15 用户指出国内可能访问不到）
- 场景**不知道**文案和语言；文字**不知道**镜头。两者只通过「滚动进度」这一个数字联系。

> 顺序按经营链路：数据自己进来 → 货自己会走 → 该补多少引擎算 → 异常自己找上门 → 人只做决定 → 助理之间自己问 → 不换系统。

### 5.2 界面拆解（段 2）

- 三层全部是 HTML/CSS 重建，不用截图：**导航层**（窄长条：logo、今日概览 / 私人助理 / 沟通 / 项目 / 日历 / 通知 / 数据告警 / 组织 / 知识库 / 零售 / 大屏）、**列表层**（对话列表：搜索框 + 若干条「库存 · 门店 07」「自动任务 · 周报」这类假标题）、**主内容层**（一段助理对话：告警卡片 + 用户回复「同意」+ 助理执行结果）。文字全部走 i18n。
- 视觉：深色玻璃面板（`rgba(10,20,36,.85)` + 1px 高光边 + 大而软的投影），沿用站内配色；不是浅色面板。
- 布局：一个 `#layers` 固定容器，`perspective: 1600px`；内部舞台 `rotateX(58deg) rotateZ(-45deg)`；三层分别 `translateZ(0 / 60px / 120px)`，在等距平面上错开摆放（导航在左后，列表在中，主内容在右前），参照 Dribbble exploded-UI 的构图。
- 动：段内进度 u∈[0,1]。u 0→0.35 飞入：三层从各自方向（导航从 −y 远处，列表从 +x，主内容从 +y 下方）沿等距轴滑入并从 translateZ +400 落到自己的高度，透明度 0→1，三层错开 0.08；0.35→0.65 停留（轻微浮动，`translateZ ± 6px` 正弦）；0.65→1 飞出：沿相反方向升起并淡出。全部用 `transform` 与 `opacity`，`will-change: transform`。
- 期间 3D 地图镜头拉远到 dist 420 并把场景整体亮度压到 0.35（`scene.setDim(t)`），让前景层清楚。
- 手机：舞台缩放 0.55，三层竖向堆叠错位更小；同样的飞入飞出。

### 5.1 极光（结尾）

一张大平面（约 900 × 600）悬在城市上空 y≈120，`ShaderMaterial` + `AdditiveBlending`：
fbm 噪声生成三四条色带（青 / 紫 / 淡金），沿 x 缓慢流动，边缘淡出。只在段 7→8 之间淡入，其它段不渲染（`visible=false`）。

## 6. 滚动与镜头

- `story.js` 每帧读 `scrollY / (docHeight - innerHeight)` 得到全局进度 `p ∈ [0,1]`，按段边界换算成 `(段号 k, 段内进度 u)`，
  调用 `scene.setProgress(k, u)`。
- `scene.js` 为每段定义一个镜头关键帧 `{target, dist, az, tilt}`；段内 `u < 0.5` 时向本段关键帧靠拢，
  `u > 0.5` 时开始向下一段插值。实际相机位置对目标位置做指数平滑（每帧 lerp 0.08），滚快了也不抖。
- 全景段（0、1、2）方位角随时间自增（慢转）；特写段方位角固定但方块自身缓慢自转。
- 不监听 `wheel`、不 `preventDefault`，滚动完全交给浏览器。
- `prefers-reduced-motion`：关掉自转和呼吸，镜头在段切换时直接跳到关键帧。

## 7. 双语

- `i18n.js` 里两张表（`zh` / `en`），每段一个 key，`applyLang()` 只改 `data-i18n` 元素的 innerHTML。
- 默认按 `navigator.language`（zh 开头用中文，否则英文）；右上角按钮切换；记 `localStorage.lang`。
- `<html lang>` 随之切换；中文字体 PingFang / Noto Sans SC，英文 Inter 回退系统字体。

### 8.1 canvas 2D 极光（降级层，重新设计）

旧站那几个椭圆径向渐变太糊、太像光斑，不用。新的做法要像**极光幕**，并与 §5.1 的 3D 极光同一套配色（青 / 紫 / 淡金），
让两种情况下的结尾看起来是同一件东西：

- **幕**：3–4 条色带，每条是一条沿 x 方向的曲线（值噪声取样的折线，`t` 缓慢推进），曲线下方画**竖向的光丝**：
  每隔 6–10px 一根，从曲线向下拉一段长度随噪声变化的渐变线（顶端亮、向下透明），这是极光「窗帘」质感的来源。
- **颜色**：色带分别取青 `#5ee0ff`、紫 `#9d8cff`、淡金 `#e8cf8f`，用 `globalCompositeOperation = 'lighter'` 叠加；
  整层用低透明度（0.35–0.5），叠在深蓝底 `#050b18` 上。
- **动**：曲线的噪声偏移随时间推进（约每秒 0.02 个噪声单位），光丝长度另有一套更快的噪声（约 0.08），
  看起来是一层慢慢漂、一层轻轻抖。
- **随滚动变**：开场只有很淡的一条带在顶部；随滚动进度带数增多、亮度提高；到结尾段全部展开，
  与 3D 版结尾的节奏一致。
- **性能**：离屏 canvas 按 0.5 倍分辨率画，再放大贴到全屏；`document.hidden` 停止；手机上光丝间距加大到 12px。
- 也用于 `prefers-reduced-motion`？不用——那种情况下 3D 仍可用，只是不动；降级层只在 WebGL 不可用时出现。

## 9. 性能

- 底图道路合并成一个 `LineSegments`（同大屏），区县挤出一次，水面合并。
- 方块共用几何，材质每种一份；七个特写方块各自一份材质，其余陪衬方块共用。
- 渲染循环只在页面可见、且（滚动进度有变化 或 动画未关闭）时跑。
- 目标：MacBook 上 60fps，iPhone 12 级别 ≥ 40fps。
